# Kasir UMKM

1. Buka `www/config.js`, isi username, sandi awal, dan nama toko untuk pembeli.
2. Upload SELURUH isi folder ke repo GitHub baru (termasuk folder tersembunyi `.github`).
3. Tab Actions: tunggu workflow "Build APK" selesai, unduh Artifacts "kasir-umkm-apk", ekstrak, lalu kirim file .apk ke pembeli bersama username dan sandinya.
4. Pembeli bisa mengganti username/sandi di Setelan > Akun pemilik, dan mengatur logo, background, alamat, warna.

Laporan (harian/mingguan/bulanan): tombol WhatsApp mengirim ringkasan teks; tombol PDF dan Word membuat file lalu membuka menu bagikan HP, pilih WhatsApp.
Data tersimpan di perangkat pembeli.
